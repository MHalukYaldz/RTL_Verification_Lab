## Topics Practiced

* Object-oriented programming
* Randomization and constraints
* Interfaces and virtual interfaces
* Mailboxes, events, and semaphores
* Transaction-based stimulus
* Generator / Driver architecture
* Monitor / Scoreboard architecture
* Self-checking testbenches
* Digital interface verification
* Simulation waveform analysis

## Verification Projects

* **D Flip-Flop** — Verification exercises and unknown input handling
* **FIFO** — Random read/write, boundary, and fill/drain verification
* **SPI** — MOSI, master, and master-to-slave verification
* **UART** — Verification exercises
* **I2C** — Next verification project
* **UVM** — Exercises and verification work in progress
