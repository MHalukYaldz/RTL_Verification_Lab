# SystemVerilog Verification

SystemVerilog verification work covering language fundamentals, class-based testbench development, constrained random stimulus, and verification environments for digital designs and communication interfaces.

## Repository Structure

| Section | Content |
|---|---|
| Part1 – SystemVerilog Essentials | SystemVerilog features used in verification and class-based testbench development |
| Part2 – SystemVerilog Projects | Verification environments for DFF, FIFO, SPI and UART |
| Part3 – UVM | UVM-based verification work |

## Verification Topics

- Object-oriented programming
- Randomization and constraints
- Interfaces and virtual interfaces
- Mailboxes, events and semaphores
- Transaction-based stimulus
- Generator / Driver
- Monitor / Scoreboard
- Self-checking testbenches
